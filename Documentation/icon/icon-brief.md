# App icon — design brief

The canonical description of the Battleship PWA app icon, so we never have to
re-describe it from scratch. Re-read this before regenerating or restyling the icon.

## Concept

A **top-down (bird's-eye) view**: we look straight down from the sky onto open water
and see a single warship. Ocean below, ship on top — nothing else. No text, no grid,
no crosshair.

## Composition

- **Background:** blue ocean, a smooth vertical gradient (lighter blue at the top,
  deeper navy toward the bottom). Full-bleed — the icon is opaque edge to edge, and iOS
  applies its own squircle rounding, so keep important detail away from the corners.
- **Ship:** white, viewed from directly above, **bow pointing up**.
  - Occupies the **bottom ~60% of the icon's height**, anchored to the bottom edge.
  - **Widest at the bottom** (the stern), ~**70% of the icon width**, with a squared,
    slightly rounded stern.
  - **Tapers as it goes up** to a clearly **pointed bow** near the vertical middle.
- **Deck detail** (so it reads as a *battleship*, not a generic boat): a slim central
  superstructure (bridge tower + funnel) and two main **gun turrets** on the centreline —
  one forward, one aft — each with three long thin barrels (forward guns point toward the
  bow, aft guns toward the stern). Rendered in light steel-grey against the white deck,
  kept subtle so the silhouette stays clean and Apple-minimal.

## Style targets

- **Apple HIG feel:** one bold subject, generous margins, smooth gradient, restrained
  detail. Simple and confident, not a detailed model kit.
- Must stay legible from **512px down to 72px** and under the iOS squircle mask.

## Production notes

- Icons are generated by a dependency-free Node renderer (procedural geometry, 4–5×
  supersampled anti-aliasing, hand-rolled PNG via `zlib`) — no `sharp`/ImageMagick/PIL on
  this machine.
- Output set lives in `public/`: `icons/icon-{72,96,128,144,152,192,384,512}x{…}.png`,
  plus `apple-touch-icon.png` (180, full-bleed — iOS masks it itself) and `favicon.ico`
  (16/32/48). Referenced from `public/manifest.webmanifest`, `src/index.html`, and
  `ngsw-config.json`.
- **Cache-busting:** installed PWA icons are sticky. When the art changes, bump the version
  suffix on every icon filename (e.g. `.v3.png` → `.v4.png`) and update all three reference
  files, so browsers, the HTTP cache, and Android's WebAPK updater fetch the new URLs.
  (iOS home-screen installs still require a manual remove-and-re-add — unavoidable.)
