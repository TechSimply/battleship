10. Ship health display
10.1. Both healths - mine and the enemy's - are on screen from the very first moment of
the game, at 100%, before anything is placed or fired. Players should see straight away
that there is a health factor and that each side has only one ship.
10.2. There is one board now, so the two healths sit side by side as horizontal bars above
it - mine and the enemy's, clearly labelled, each about half the width of the board.
10.2.1. The wording on screen must never suggest a fleet or several ships - this is a duel
of one ship against one ship, so the labels read "Your ship" and "Enemy ship".
10.3. The bar carries the little ship icon in the ship's current colour, and the percentage,
so the ship and the number always match the colour of the ship on the board.
10.4. The bar empties from its far end as the health falls, and its colour follows rule 6.4
- green at 100%, orange at 50%, almost red at 10%.
10.5. Next to each board label there is a ship counter, so nobody mistakes this for the
classic battleship game with a fleet: it says 1 for the whole game and turns 0 the moment
that ship is wrecked. It is painted in the ship's current colour like everything else.
10.6. Showing the health reveals nothing about where a ship is - only how hurt it is.

11. Collision
11.1. Nothing stops the two ships from sailing into the same square. A player who moves onto
the square the other ship is on rams it: both ships are wrecked.
11.2. A collision ends the round with no winner - neither player scores a point (rule 8).
11.3. That one square shows both wrecks, and the crash is played as a crash: the two hulls
run into each other along the course the rammer sailed, the impact flashes and throws out a
shockwave, and the square itself shakes. It must not look like the ordinary sinking.
11.4. The collision is settled before the fire is: a burning ship that rams on the very move
that would have taken it to 0% does not lose - the round is a draw. So a player never loses
on the last step of their own fire.
11.5. Placement is simultaneous and hidden, so both players can pick the same starting square.
That is a ram too - both wrecked, no point, before a single shot. It is not prevented: telling
the second player "that square is taken" would tell them exactly where the first one is.
